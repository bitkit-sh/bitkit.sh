# bitkit tokens

Use `brand/tokens.css` custom properties (`--brand-primary`, `--brand-ink`, `--brand-paper`, `--brand-font-heading`, `--brand-radius`) instead of literal values. `brand/tokens.json` carries the same values in the Design Tokens format.

- Text on paper uses ink. Text on primary uses #ffffff.
- Keep body text at a contrast ratio of 4.5:1 or more; check new pairs before using them.
- The mark is `brand/assets/mark.svg`; do not redraw it.
