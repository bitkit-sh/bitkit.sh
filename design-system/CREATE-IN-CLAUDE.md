# Create the bitkit design system in Claude

In Claude, ask:

> Create a Claude Design System titled "bitkit" from the files in `design-system/project/` of my bitkit kit. Upload `assets/Logos/mark.svg` as a Logos asset, keep every token value exactly, and write the index last.

Then run `just publish` and ask Claude to sync the system to https://kit.bitkit.sh.
