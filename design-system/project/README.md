# bitkit

Brand identity in a box: one kit, every surface.

This design system is generated from `bitkit.kit.json` and edited in Claude. The live site is https://bitkit.sh; this reference lives at https://kit.bitkit.sh.

## Content

- Voice: more formal, more serious, bolder.
- Say: Show the kit, then the claim.
- Say: Name the file a feature lives in.
- Avoid: Growth-hack language.
- Avoid: Promises about follower counts.
- Bio: bitkit turns a brand into one kit: brand book, tokens, profile sheets, repo, CI, Cloudflare services, and an agent team. You create the accounts; bitkit prepares the rest.

## Color

- `paper` is the page; `raised` holds cards and panels; text is `ink`, secondary text `ink-muted`.
- `primary` is the one strong color: primary buttons, links, the mark, focus rings. Text on it is `on-primary`.
- `accent` highlights and always travels with a word.
- Light and dark themes define the same tokens. Ink on paper: 16.4:1 light, 17.7:1 dark.

## Type

- Bricolage Grotesque for headings (`hero`, `title`), Hanken Grotesk for text (`lede`, `body`, `label`, `fine`), mono for handles and identifiers.
- Sentence case everywhere. Handles stay as written: `@bitkitsh`.

## Shape and space

- Radii: `radius-s` chips, `radius-m` buttons and cards, `radius-l` panels.
- Spacing: `space-2` inside controls, `space-4` card padding, `space-6` between cards, `space-10` sections.

## Iconography and mark

- The mark is a seal monogram reading “b” in `primary` (`assets/Logos/mark.svg`). Never redraw or recolor it.
